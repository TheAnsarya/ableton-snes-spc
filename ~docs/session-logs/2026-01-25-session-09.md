## Focus: S-DSP Hardware Constraints Validation

This session focused on ensuring all implemented features properly map to real SNES S-DSP hardware capabilities and constraints.

## Objective

The user requested verification that all features translate back to SPC files and limit the plugin to sounds, channels, and effects that work on actual SPC chip and SNES hardware.

## Work Completed

### 1. Created SnesDspLimits Constants Class

Created [src/SpcPlugin.Core/Hardware/SnesDspLimits.cs](../src/SpcPlugin.Core/Hardware/SnesDspLimits.cs) - A centralized reference for all real S-DSP hardware constraints:

**Memory Limits:**
- 64KB total audio RAM
- Echo buffer up to 30KB (15 * 2KB)
- Sample data must avoid echo buffer region

**Voice Constraints:**
- 8 hardware voices
- Signed 8-bit volumes (-128 to 127)
- 14-bit pitch values (0-16383)
- 256 sample directory entries

**BRR Format:**
- 16 samples per 9-byte block
- Range values 0-12
- 4 filter modes

**ADSR/GAIN:**
- Attack 0-15, Decay 0-7
- Sustain level 0-7, rate 0-31
- GAIN values 0-127

**Echo:**
- Delay 0-15 (16ms per unit)
- 8 FIR coefficients (signed 8-bit)
- Feedback -128 to 127

**Utility Methods:**
- Validation helpers for all values
- Clamping functions
- Frequency/pitch conversion
- BRR block alignment
- Echo buffer size calculation

### 2. Updated ChannelMixer for Hardware Compliance

Enhanced [ChannelMixer.cs](../src/SpcPlugin.Core/Editing/ChannelMixer.cs):

- **Phase Inversion**: Added support for S-DSP negative volume (phase inversion)
  - Real hardware uses signed 8-bit volumes
  - Negative values = 180° phase shift
- **Pitch Modulation Note**: Voice 0 cannot have pitch mod enabled (no previous voice)
- **Volume Calculations**: Now use `SnesDspLimits.MaxVolume` and `ClampVolume()`
- **Documentation**: Added notes explaining S-DSP register mappings

### 3. Updated SampleBankManager for Echo Buffer Awareness

Enhanced [SampleBankManager.cs](../src/SpcPlugin.Core/Editing/SampleBankManager.cs):

- **Echo Buffer Respect**: Samples cannot overlap with echo buffer
  - `EchoBufferAddress` and `EchoBufferSize` properties
  - `SampleDataEnd` respects echo buffer location
- **Memory Reporting**: `AvailableMemory` accounts for echo buffer
- **Import Validation**: Rejects samples that would overlap echo buffer
- **Compact Operation**: Respects echo buffer boundary

### 4. Added Echo Buffer Properties to SpcEditor

Added to [SpcEditor.cs](../src/SpcPlugin.Core/Editing/SpcEditor.cs):

- `EchoBufferAddress`: Returns ESA register * 0x100
- `EchoStartPage`: Gets/sets the ESA register directly

### 5. Updated LoopPointEditor and VoiceMeter

Both now use `SnesDspLimits` constants instead of magic numbers:
- `SnesDspLimits.BrrSamplesPerBlock`

## S-DSP Features Verified as Implemented

All implemented features map to real hardware:

| Feature | S-DSP Register/Capability |
|---------|--------------------------|
| Voice volume L/R | V0L-V7L ($x0), V0R-V7R ($x1) |
| Voice pitch | P(L/H) ($x2/$x3) - 14-bit |
| Voice source | SRCN ($x4) |
| ADSR envelope | ADSR1/2 ($x5/$x6) |
| GAIN envelope | GAIN ($x7) |
| Echo per-voice | EON ($4D) bits |
| Noise per-voice | NON ($3D) bits |
| Pitch mod per-voice | PMON ($2D) bits |
| Main volume | MVOL_L/R ($0C/$1C) |
| Echo volume | EVOL_L/R ($2C/$3C) |
| Echo feedback | EFB ($0D) |
| Echo delay | EDL ($7D) - 0-15 |
| FIR filter | FIR ($xF) - 8 coefficients |
| Sample directory | DIR ($5D) |
| Echo buffer location | ESA ($6D) |
| BRR samples | Native format, loop flags |

## Features NOT Implemented (By Design)

These were avoided as they don't exist on real hardware:
- ❌ More than 8 voices
- ❌ Sample rates other than 32kHz
- ❌ Audio formats other than BRR
- ❌ Effects beyond echo/FIR (no reverb, chorus, etc.)
- ❌ Voice-specific echo settings (only on/off per voice)
- ❌ Pitch values beyond 14-bit
- ❌ Volumes beyond signed 8-bit
