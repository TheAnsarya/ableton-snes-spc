Attempted to enable custom views (ENABLE_CUSTOM_VIEWS=ON) but discovered significant VSTGUI 4.x API compatibility issues:

**Issues Found:**
- `ViewCreatorAdapter` class requires proper includes from `vstgui/uidescription/iviewcreator.h`

- `UIViewFactory::registerViewCreator()` API has changed
- `IControlListener` requires different header
- `KeyboardEventConsumeState` moved to different namespace

## Technical Discoveries

### VSTGUI 4.x API Changes
The VSTGUI SDK has undergone significant API changes:

1. **Drawing API:**
   - Old: `context->moveTo(x, y); context->lineTo(x2, y2);`
   - New: Uses `CGraphicsPath` for path-based drawing

2. **View Creation:**
   - Old: `VSTGUI::UIViewFactory::registerViewCreator()`
   - New: Registration mechanism changed

3. **Include Structure:**
   - View creator base classes require specific includes
   - Attribute constants moved to detail subfolder

### Build Configuration
CMake now supports two build modes:
- `ENABLE_CUSTOM_VIEWS=ON` - Full GUI with visualizers (requires API updates)
- `ENABLE_CUSTOM_VIEWS=OFF` - Basic GUI with standard VSTGUI controls
