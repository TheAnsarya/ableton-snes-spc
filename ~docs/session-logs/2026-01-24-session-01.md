## Technical Notes

### Build Configuration
- Successfully builds with .NET 10
- Native AOT compilation supported
- CMake configures correctly with VST3 SDK
- All required SDK targets created

### Architecture Strengths
- Clean separation: Emulation → Audio → Interop → VST3
- Real-time safe audio processing (no allocations in hot path)
- Proper threading (UI separate from audio)
- Comprehensive native exports for C++ interop

### Performance Characteristics
- Native sample rate: 32 kHz (hardware accurate)
- Resampling to any DAW sample rate
- CPU cycles per sample: 32 (~1.024 MHz / 32 kHz)
- Buffer size: 8192 samples pre-allocated
- Waveform capture: 4096 sample ringbuffer
